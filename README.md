# ARDD Synthesis

A personal knowledge base built from the Aging Research and Drug Discovery (ARDD) YouTube channel.

## Goals

- Use individual ARDD talks as entry points into aging biology subfields.
- Build aging biology knowledge 'breadth' first and routinely expand on a list of subjectively currated themes using review articles, textbook subsections, or the speakers' own papers.
- Keep a record of computational/mathematical methods used in each talk and continuously fill my gaps in my understanding and develop an ability to apply such methods to my own projects.
- Potentially replicate an analysis or pipeline.
- Network with people in the aging field to gain additional clarity or bounce off my own ideas once they develop enough.
